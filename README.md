# Детекция ботов по событиям Авито

На платформе финальный файл получил Precision при Recall ≥ 70% равный 0,81360. Код для получения этого файла находится в [solution.ipynb](solution.ipynb).

## Что внутри

Я начал с простой модели по числу событий и разных объявлений. Потом добавил паузы между действиями, просмотры, запросы, данные о платформе и курсоре. Больше всего помогли общие объявления разных куки за один день и похожие маршруты за предыдущие семь дней. В финале смешал CatBoost (60%) и HistGradientBoosting (40%). Веса сохранил после небольшого выигрыша 60/40 над 50/50 на предварительных временных проверках. Модель использует 132 признака.

Проверял её по времени. Обучался на ранних днях, проверял на более поздних. В ноутбуке есть простая базовая модель и сравнение вариантов на 120, 126 и 132 признаках. Другие идеи тоже пробовал, но в финальную версию не добавил, потому что они не давали устойчивого выигрыша.

Перед расчётом признаков оставляю только события с `window_start_ts <= event_ts < window_end_ts`. Для части признаков удаляю точные повторы, а исходные счётчики и интервалы считаю с ними. Так воспроизводится отправленный результат. Признаки предыдущих дней не используют будущие события и метки других куки.

## Как запустить

Я проверял код на Python 3.13.5. Установите библиотеки командой `pip install -r requirements.txt`. Выданные `train.csv`, `test.csv` и `events.csv.gz` положите в папку `data/`. Файлы `sample_submission.csv` и `metric.py` должны лежать рядом с ноутбуком.

Запустите все ячейки [solution.ipynb](solution.ipynb) сверху вниз. Последняя создаст `submission.csv`. Предсказания соединяются с образцом по `cookie_id`, поскольку порядок строк в `test.csv` и `sample_submission.csv` различается.

Положительный класс в этих данных составлен из известных сервисов сбора данных. Для нового сервиса или другого периода качество может отличаться.
